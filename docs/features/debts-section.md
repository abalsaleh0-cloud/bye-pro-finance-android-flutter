# قسم الديون

## التبويبات

يتكون القسم من تبويبين:

1. **دين لك (دائن)**
2. **دين عليك (مدين)**

كل تبويب يعرض الديون المطابقة لاتجاهه فقط.

## الإضافة

زر الإضافة موجود في شريط التطبيق العلوي بجانب الإعدادات. يفتح خيارين:

- **إضافة دين لك (دائن)**
- **إضافة دين عليك (مدين)**

بعد اختيار الاتجاه تفتح نافذة الحقول التالية فقط:

1. اسم الشخص.
2. المبلغ.
3. التاريخ.
4. ملاحظة.

لا يوجد اختيار اتجاه إضافي داخل النافذة، ولا يطلب من المستخدم إدخال المبلغ المتبقي يدوياً. المبلغ المتبقي يبدأ مساوياً للمبلغ الأصلي، ثم تتغير قيمته عبر تسجيل الدفعات.

## سلامة البيانات

- يستخدم القسم جدولي الديون ودفعات الديون الحاليين.
- يشتق الشهر المعروض من التاريخ الكامل المختار.
- عند تعديل دين لديه دفعات مسجلة، يُحافظ على مجموع المدفوع سابقاً ويُحسب المتبقي من المبلغ الجديد.
- تبقى سجلات الدفعات وسجلها مرتبطين بالدين نفسه.
