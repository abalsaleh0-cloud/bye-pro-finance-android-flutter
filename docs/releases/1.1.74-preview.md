# النسخة التجريبية 1.1.74 Preview

- الإصدار: `1.1.74+175`.
- تأجيل تحديث أيقونة المشغّل إلى ما بعد بناء إطار الواجهة لتجنب تنفيذ تأثيرات Android أثناء البناء.
- تصحيح أسماء نشاطَي الأيقونة لتتبع `applicationId` الفعلي في الإنتاج والمعاينة.
- تفعيل الأيقونة الجديدة قبل تعطيل القديمة حتى لا يبقى التطبيق من دون مدخل تشغيل.
- إضافة إنشاء نسخة احتياطية JSON واستعادة ذرية تشمل سجلات العمل والمنزل والتحويلات والفواتير والديون وإعدادات التطبيق.
- إضافة PIN بطول 4–8 أرقام باستخدام PBKDF2 مع salt عشوائي، وتخزين آمن على الجهاز.
- إضافة فتح بالبصمة عبر `local_auth` مع PIN كخيار احتياطي.
- لا تُضمّن بيانات PIN أو البصمة في ملف النسخة الاحتياطية.
- يلزم اختبار تبديل الثيم والأيقونة والنسخ والاستعادة والبصمة على هاتف فعلي؛ نجاح CI لا يعادل اختبار الجهاز.
