# BYE PRO Finance 1.1.98 — Gemma download state fix

**Version:** 1.1.98+199  
**Platform:** Android Production / Release  
**Scope:** Android repository only

## Changes

- The model action now consistently reads **Download model** whenever Gemma is not ready. A generic error state no longer relabels the initial download action as Retry.
- The LiteRT-LM engine is initialized before the Gemma model registry is queried, preventing a registry check from running before engine registration.
- Download and verification errors now display a short technical cause instead of hiding every failure behind one generic message.
- The Delete model action is shown only when the model registry confirms an installed model. A simple download failure will not expose a destructive delete action.
- Existing model files are not removed as part of error handling or retry.

## Verification boundary

Automated build and test checks validate the application package and code paths. A successful download and first inference still require a real-device test; this release note does not claim that a multi-gigabyte download was completed on a handset.
