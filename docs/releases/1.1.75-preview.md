# النسخة التجريبية 1.1.75 Preview

- الإصدار: `1.1.75+176`.
- استقرار تبديل المظهر الداكن والفاتح وفصل تغيير أيقونة المشغّل عن بناء إطار الواجهة.
- إصلاح أسماء aliases الخاصة بأيقونتي المشغّل لمعرّفي الإنتاج والمعاينة.
- إضافة إنشاء نسخة احتياطية JSON واستعادة ذرية لسجلات العمل والمنزل والتحويلات والفواتير والديون وإعدادات التطبيق.
- ملفات النسخ الاحتياطي غير مشفّرة؛ يجب حفظها في موقع خاص وآمن. لا تتضمن ملفات النسخ PIN أو بيانات البصمة.
- إضافة PIN بطول 4–8 أرقام باستخدام PBKDF2 مع salt عشوائي وتخزين آمن.
- إضافة فتح بالبصمة عبر `local_auth` مع PIN كوسيلة بديلة.
- تفعيل بوابة PIN في نسخ Profile/Release، مع إبقاء وضع Debug متاحاً للاختبارات والتطوير.
- يلزم اختبار تبديل الثيم والأيقونة والنسخ والاستعادة والبصمة على الهاتف الفعلي؛ نجاح CI لا يعادل اختبار الجهاز.
