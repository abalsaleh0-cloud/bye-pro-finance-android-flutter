# Bye Pro Finance 1.1.95 — Preview

**رقم البناء:** `196`  
**المنصة المستهدفة:** Android ARM64  
**المسار:** معاينة Profile — توقيع Preview فقط  
**الحالة:** الفرع الموحّد قيد التحقق عبر Flutter CI.

## تكامل الذكاء الاصطناعي

- دمج Gemma فوق أحدث فرع للمحرك المالي المحلي، مع الحفاظ على قواعد الرصيد، وسلامة التعديل والحذف والدفعات، ورسائل الأخطاء المعرّبة.
- توصيل Gemma بجميع أفعال `ActionRegistry`: العمل، السلف والدفعات، تحويلات المنزل، المصروفات والتصنيفات، الفواتير والإيجارات ودفعاتها، الديون ودفعاتها، قراءة السجلات والملخص، والتنقل.
- توفير مخططات أدوات موحّدة مع الأفعال الفعلية، واختبار تغطية جميع الأفعال.
- دعم التعديل الجزئي بمعرّف السجل دون مطالبة النموذج باختراع الحقول التي لم يطلب المستخدم تغييرها؛ يستعيد التطبيق بقية الحقول من قاعدة البيانات قبل المعاينة.
- استخدام `LocalRuleAssistantEngine` كمسار احتياطي عند إيقاف Gemma أو عدم جاهزية النموذج أو فشل تفسير أمر نصي.
- تفعيل تحليل الصور وملفات WAV عندما يكون Gemma جاهزاً وعلى جهاز يفي بحد الذاكرة.
- الحفاظ على بطاقة مراجعة العملية والتأكيد الصريح قبل أي كتابة مالية.

## الصوت والتنزيل

- يفضّل الميكروفون التعرف العربي المحلي ثم ينتقل إلى خدمة Android الافتراضية عند غياب حزمة العربية؛ قد يتطلب المسار الافتراضي إنترنت.
- تنزيل Gemma عبر خدمة Android الأمامية مع طلب إذن الإشعارات، وعرض نسبة التقدم والحجم التقديري المنزّل من إجمالي الملف.
- التحقق من حجم النموذج وبصمة SHA-256 قبل إعلان الجاهزية.

## حالة التحقق

سيتم اعتماد APK المعاينة فقط بعد نجاح توليد الملفات، والتنسيق، والتحليل، والاختبارات، وبناء ARM64 والتحقق من التوقيع في GitHub Actions. لم يتغير مفتاح توقيع الإنتاج؛ تستخدم نسخة المعاينة مفتاح Preview المستقل.
