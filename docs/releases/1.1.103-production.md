# BYE PRO Finance 1.1.103 — Gemma context and tool routing

**Version:** 1.1.103+204  
**Platform:** Android Production / Release  
**Scope:** Android application only. The web source repository is unchanged.

## Gemma runtime
- Increase the LiteRT-LM context window from 2,048 to 4,096 tokens. This budget includes the system instruction, tool schemas, conversation context, current user message, and generated answer.
- Replace the oversized system instruction with a shorter safety-focused Arabic instruction.
- Send no finance tool schemas for ordinary general conversation.
- Route finance prompts to only the relevant read, write, payment, delete, or navigation tools; reject any tool call that was not exposed for the current turn.
- Keep a bounded recent dialogue excerpt (900 characters) in the model prompt while retaining the full chat history in the app.
- Extend the local generation timeout to avoid cancelling slower on-device inference prematurely.
- Keep CPU backend, single active session, and existing image/audio capability guards.

## Model and data preservation
- Keep the exact installed `gemma-4-E2B-it.litertlm` file and its SHA-256 verification.
- No model uninstall, file replacement, or download.
- No application ID, production signing key, database schema, financial records, or web repository changes.

## Verification
- Flutter static analysis and automated tests.
- Signed ARM64 Production APK with package ID and signing certificate checked against the existing production identity.
- Final Gemma inference must be confirmed on the user's Android device; CI cannot execute the model on that handset.
