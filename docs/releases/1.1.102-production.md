# BYE PRO Finance 1.1.102 — Gemma context and official Android launcher icon

**Version:** 1.1.102+203  
**Platform:** Android Production / Release  
**Scope:** Android application only. The web source repository is unchanged.

## Gemma context reliability
- Shorten the system instruction from roughly 4,000 Arabic characters to a focused 1,234-character safety and behavior prompt.
- Attach only the finance tool schemas relevant to the user's current request. General writing, explanations, greetings, and ordinary chat no longer carry the full financial action catalog.
- Keep the most recent five dialogue messages and cap their combined transcript at 480 characters before inference.
- Bound the supplemental expense-category catalog to avoid unbounded prompt growth.
- Preserve the 2,048-token mobile context window and its CPU backend rather than increasing memory consumption on the handset.
- Keep personal financial facts restricted to validated app read actions and preserve confirmation before financial writes.

## Official Android launcher icon
- Restore the existing original BP bitmap at `android/app/src/main/res/drawable-nodpi/ic_launcher_dark.png` as the application icon.
- Point both Android launcher aliases and the application/round icons to that official bitmap; do not use the unrelated wallet artwork that was incorrectly wired in 1.1.101.
- Keep the existing light/dark alias switching code intact.
- Add a release-workflow assertion so a future manifest change cannot silently replace the official BP icon with the unrelated mipmap artwork.

## Preservation
- Keep the original application ID, production signing configuration, existing database, installed Gemma model, and app storage unchanged.
- No Gemma model download, removal, or replacement is part of this release.
- The web source repository is unchanged.

## Verification boundary
- Flutter analyzer, unit/widget tests, ARM64 preview build, and signed production build must pass before delivery.
- The Gemma runtime must still be tested on the handset after installing this signed update. This release does not claim a handset inference pass before that test.
