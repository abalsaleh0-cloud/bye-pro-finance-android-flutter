# BYE PRO Finance 1.1.99 — Conversational AI chat

**Version:** 1.1.99+200  
**Platform:** Android Production / Release  
**Scope:** Android application only; web source repository is unchanged.

## Conversation experience

- Treat the on-device Gemma assistant as a continuing Arabic conversation partner as well as a financial assistant.
- Include a bounded recent dialogue transcript in each Gemma turn so follow-up questions, references, clarifications, and topic continuity can be understood.
- Keep personal financial figures and tool/database results out of the free-form model transcript; use the application's validated read tools for personal financial facts.

## Chat organization

- Save independent conversation threads locally on the device.
- Create a new conversation without deleting earlier conversations.
- Assign a title from the first user message.
- Browse saved conversations, switch between them, and delete a selected conversation after an explicit confirmation.
- Deleting a conversation deletes only its chat messages, not financial records or other conversations.
- Migrate existing single-chat history from `ai_chat_messages_v1` into the new multi-conversation store without discarding existing messages.
- Retain a bounded number of conversations and messages to keep local storage manageable.

## Conversation usability

- Automatically scroll to the latest message after sending, receiving a response, restoring a conversation, or switching conversations.
- Preserve the composer and the existing reviewed-confirmation flow for financial writes.

## Verification boundary

Flutter CI and the signed Android Production Release workflow provide the automated verification. The final on-device behavior, including Gemma inference and scroll ergonomics on the user's phone, still requires a real-device check.
