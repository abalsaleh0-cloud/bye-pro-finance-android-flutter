# Bye Pro Finance 1.1.87 Preview

- Version: `1.1.87+188`.
- The application still starts in Dark mode on a fresh install.
- Theme selection updates the UI immediately and now awaits local database persistence before the settings action completes.
- Added regression coverage for the Dark default, Light/Dark switching, and restoring the saved selection after a provider/process restart.
- Launcher alias changes remain deferred until the Activity is stopped. The last successfully applied mode is remembered so an already-correct launcher alias is not needlessly toggled.
- The AI composer remains compact and follows the supplied Telegram reference: paperclip attachment on the left, one-line idle message field, and round blue contextual microphone/send action on the right. The obsolete emoji test key has been renamed to reflect the actual attachment control.
- No web source-of-truth files or production signing key were changed.
- CI build and APK signing verification are required for this preview before release.
- Device-level verification of the reported exit when switching to Light mode is still required; automated Flutter tests cannot prove behavior on the user's handset.
