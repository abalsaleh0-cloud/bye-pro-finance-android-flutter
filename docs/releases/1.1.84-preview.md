# Bye Pro Finance 1.1.84 Preview

## Android appearance and launcher icon
- Theme changes continue to apply immediately inside the app.
- Launcher icon changes are queued and applied only after the activity leaves the foreground. This avoids OEM launcher refresh broadcasts returning the user to the home screen while they are actively using the app.
- The launcher artwork remains the existing PNG assets. The dark icon remains the initial/default icon; the light icon is selected after the app backgrounds when Light mode is active.

## AI chat composer
- No composer geometry was changed in this release because the exact Telegram reference screenshot has not been located in the accessible prior-chat files. The requested visual match remains pending that exact reference; no substitute design was introduced.
