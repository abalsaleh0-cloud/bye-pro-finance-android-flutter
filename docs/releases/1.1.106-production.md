# BYE PRO Finance 1.1.106 — Previous-month work outstanding details

**Version:** 1.1.106+207  
**Platform:** Android Production / Release  
**Scope:** Android application only. The web source repository is unchanged.

## Work dashboard
- Calculate outstanding balances for every month before the selected month.
- Sum only positive unpaid monthly balances; advances and payments remain assigned to their original month.
- Keep the selected month's outstanding amount separate and include it only once in the cumulative total.
- Exclude future months from previous-month balances.
- Add a collapsible dashboard panel listing each previous month and its remaining amount.
- Show an explicit empty state when no previous-month balance remains.
