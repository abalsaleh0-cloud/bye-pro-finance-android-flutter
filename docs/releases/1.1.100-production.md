# BYE PRO Finance 1.1.100 — Local AI monthly bills and rent

**Version:** 1.1.100+201  
**Platform:** Android Production / Release  
**Scope:** Android application only; the web source repository remains unchanged.

## Local AI billing commands

- Expand Arabic natural-language recognition for monthly invoices, subscriptions, and recurring rent.
- Recognize plural wording and common imperative forms, including "أضيف", "الإيجارات الشهرية", and "الفواتير الشهرية".
- Parse recurring frequency separately from the invoice title so words such as "شهرية" are not stored as part of the bill name.
- Preserve the existing ActionRegistry validation, financial record preview, and explicit user confirmation before a write.

## Immediate screen refresh

- Refresh the home-bills list and bill-related monthly summaries after an assistant-created, edited, deleted, or paid bill.
- Refresh the same projections after undoing an assistant bill action.
- Avoid requiring the user to leave the screen or restart the app to see a successfully saved bill or rent entry.

## Verification boundary

Automated Flutter analysis and tests plus the signed Android Production build verify the code and packaging. Final behavior must still be confirmed on the user's device, especially the interaction between the active home screen and saved local records.

## First-install appearance

- Use Android's current system appearance as the default on a fresh install.
- Keep explicit Light/Dark choices when an existing user has already saved a preference.
- Keep manual appearance selection available in Settings.
