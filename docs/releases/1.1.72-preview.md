# النسخة التجريبية 1.1.72 Preview

- إصدار التطبيق: `1.1.72+173`.
- معالجة متطلبات بناء Android لمكتبة الإشعارات الحالية.
- رفع compileSdk إلى Android API 37 مع تثبيت المنصة المطلوبة في CI.
- تفعيل Core Library Desugaring وإضافة `desugar_jdk_libs 2.1.4`.
- لم يتغير targetSdk أو minSdk أو طلبات الأذونات نتيجة هذا الإصلاح.
- لم تُعدّل ميزات النسخ الاحتياطي أو الاستعادة أو البصمة أو رمز PIN؛ هي منفذة مسبقاً كما أكد المستخدم.
- احتفظ سلوك ميكروفون المساعد كما هو: التعرف العربي المباشر، وإدراج النص في الحقل للمراجعة قبل الإرسال.
