# Bye Pro Finance 1.1.86 Preview

- Version: `1.1.86+187`
- AI message composer reshaped to match the supplied Telegram reference: compact pill, single attachment control on the left, compact one-line idle input, and circular blue voice/send action.
- Text input grows vertically only as content is entered, up to four lines.
- Fresh installs now start in Dark mode; an explicitly saved System preference remains respected.
- Launcher icon switching is deferred until the Activity is fully stopped, not merely paused, to avoid changing launcher components during transient overlays; dark remains the initial launcher icon.
- The previous preview checks passed. This revision must pass its own CI build before an APK is published.
- Device-level theme-switch validation is still required; CI does not prove the reported exit-on-theme-change is fixed on the user's handset.
- The production repository's default branch and web source-of-truth project are unchanged.
